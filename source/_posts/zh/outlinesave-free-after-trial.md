**可以。OutlineSave 已有的 7 天免费试用结束后，免费版仍可继续使用。** 免费试用到期不等于免费版到期。是否提供新试用入口，以你安装的插件版本为准。

## 试用结束后，哪些功能仍然免费？

- 查看和搜索完整两级目录；
- 每个 ChatGPT 对话前 100 条一级目录及已加载条目的免费跳转，二级标题跟随一级条目；
- 高亮、下划线、备注、书签及筛选；
- 不限次数的 Markdown / JSON 导出；
- 每周共 3 次 HTML/PDF 导出，以平台支持的格式为准。

## 免费版和 Pro 有什么区别？

| 功能 | 免费版 | Pro |
| --- | --- | --- |
| 完整目录查看、搜索 | 可用 | 可用 |
| ChatGPT 目录跳转 | 前 100 条一级及已加载条目 | 全部条目 |
| 高亮、备注、书签 | 可用 | 可用 |
| Markdown / JSON 导出 | 不限次数 | 不限次数 |
| HTML / PDF 导出 | 每周共 3 次 | 不限次数 |

ChatGPT、Gemini、Claude 和 DeepSeek 的功能可能不同。具体权益请参考[官方价格与权益说明](https://wisteriasoftware.uk/zh-Hans/outline-pro.html)及插件内信息。已有付费许可证保留原有条款。

## 为什么 HTML 导出值得尝试？

离线 HTML 将对话保存为可导航的本地知识页，可保留目录、已有标注和书签，并支持代码、公式等内容。PDF 更适合固定版式阅读和打印。

## 常见问题

### 7 天之后必须付费吗？

不需要。Pro 是可选升级，不是继续使用免费版的必要条件。

### 免费 HTML 导出额度什么时候恢复？

HTML/PDF 每周共 3 次，周一 00:00 UTC 重置，未用完的额度不累计。

### 没有 Pro，还能整理长对话吗？

可以。完整目录查看和搜索、标注及书签继续免费，超出免费跳转范围的未加载条目可能需要 Pro。

### Outlinesave 会上传我的 AI 对话吗？

OutlineSave 采用本地优先设计，不向自己的服务器上传 AI 对话正文。原始对话仍由相应 AI 平台处理；可选 Google Drive 备份使用你自己的授权账号。
