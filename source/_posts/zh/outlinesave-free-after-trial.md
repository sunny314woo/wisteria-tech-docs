**可以。Outlinesave 的 7 天免费试用结束后，插件不会因此停止工作，也不要求你必须购买 Pro 才能继续使用。**

这是一个常见误解：**免费试用期结束 ≠ 免费版到期。**

## 试用结束后，哪些功能仍然免费？

你仍然可以使用 Outlinesave 的基础整理功能，包括：

- 两级对话目录与长对话导航；
- 高亮、下划线、备注与书签；
- 对话内容的搜索与筛选；
- Markdown 导出；
- **离线 HTML 导出每周 1 次**（额度每周一重置）。

这些功能适合日常阅读、查找旧回答、标记重点，以及偶尔将重要对话保存到本地。

## 免费版和 Pro 有什么区别？

| 功能 | 免费版（试用结束后） | Pro |
| --- | --- | --- |
| 对话目录与导航 | 可使用 | 可使用 |
| 高亮、备注与书签 | 可使用 | 可使用 |
| Markdown 导出 | 可使用 | 可使用 |
| 离线 HTML 导出 | 每周 1 次 | 不限次数 |

部分功能可能处于公测阶段，具体可用额度请以扩展内显示的信息为准。

## 为什么 HTML 导出值得尝试？

普通的聊天记录保存，往往只留下大段文字。Outlinesave 的离线 HTML 导出则旨在把长对话保存为**可导航的本地知识页**，保留目录和标注，并支持在导出的页面中查阅代码、数学公式等内容。

如果你只是偶尔备份一段重要对话，每周一次的免费额度可能已经够用。如果你需要频繁归档多个对话，Pro 的不限次数 HTML 导出会更合适。

## 常见问题

### 7 天之后必须付费吗？

**不需要。** 可以继续使用免费版。付费是为了获得更高的 HTML 导出额度等 Pro 权益，而不是解锁整个插件的基本使用资格。

### 免费 HTML 导出额度什么时候恢复？

免费版每周可导出一次离线 HTML，**每周一重置**。

### 没有 Pro，还能整理长对话吗？

可以。目录、标注、书签等基础整理功能不因免费试用结束而整体失效。

### Outlinesave 会上传我的 AI 对话吗？

Outlinesave 采用本地优先的设计，不需要创建 Outlinesave 用户账号，也不以将 AI 对话上传到其服务器作为使用前提。请注意，ChatGPT、Gemini 等平台本身的数据处理规则仍由相应平台决定。
