Outlinesave 支持给 ChatGPT 长对话添加彩色书签、按颜色筛选，再将符合条件的问答**单独导出为 HTML 或 PDF**。**导出文件的目录也会保留书签及颜色标记**，便于离线定位、阅读和复习。

## 1. 如何给 ChatGPT 的目录添加彩色书签？

Outlinesave 的两级目录支持分别标记：

- **一级书签**：标记用户提问对应的问答轮次。
- **二级星标**：标记 AI 回答中的某个标题或章节。

实际操作是：

1. **第一次点击**目录条目的书签图标（或二级标题的星标），立即添加一个**未分类**书签。
2. **再次点击**已点亮的图标，打开书签颜色选择器。
3. 根据自己的分类习惯，选择**红色、黄色或绿色**。
4. 如果要取消书签，选择器中点击**普通书签图标**（二级标题对应取消星标）。

修改书签颜色无需先删除原书签。书签颜色也不会改变正文已有的高亮颜色。

## 2. “未分类”书签是什么意思？一定要选择颜色吗？

**不需要。未分类是第一次添加书签时的默认状态，并不是第四种可选颜色。**

如果只是想快速收藏一个结论，点一次就够了；稍后需要归类，再点一次选择颜色。

例如，你可以自行约定以下分类（颜色本身不带固定语义）：

| 标记 | 示例用途 |
| --- | --- |
| 未分类 | 暂时收藏，稍后整理 |
| 红色 | 待处理、需要修改 |
| 黄色 | 待复习、继续研究 |
| 绿色 | 已验证、已解决 |

未分类书签沿用默认书签样式。在顶部筛选时，它包含在**全部书签**中；当前没有单独的“只显示未分类”筛选按钮。

如果要把已经分类的彩色书签恢复为未分类状态，可以先移除再重新添加。

## 3. 如何按书签颜色筛选长对话？

点击 Outlinesave 目录**顶部的书签筛选按钮**，可以选择：

- **全部书签**：所有已经点亮的一级书签和二级星标，包括未分类。
- **红色**：仅查看与红色书签相关的目录条目。
- **黄色**：仅查看与黄色书签相关的目录条目。
- **绿色**：仅查看与绿色书签相关的目录条目。

如果一个一级问题里，只有某个二级标题被标记为红色，筛选红色时仍会保留该标题所属的一级问题，确保目录有必要的上下文。

部分旧版书签保留的历史颜色不会因此被删除；不属于当前三种可选颜色的旧标记仍可从“全部书签”查看。

**筛选只是改变当前目录视图，并不会删除未显示的对话或书签。**

## 4. 怎样只把筛选后的书签导出成 HTML 或 PDF？

如果一段 ChatGPT 对话有数百轮，但只有少数问题需要保存，可以：

1. 给重要的一级问题或二级标题添加书签。
2. 按需要选择红、黄、绿三种颜色，或者保留未分类状态。
3. 点击顶部书签筛选按钮，选择**全部书签**或指定颜色。
4. 打开 Outlinesave 的**导出菜单**。
5. 选择 **HTML · 当前书签筛选**，或 **PDF · 当前书签筛选**。

例如，先把待解决的问题标为红色，再筛选红色并导出 PDF，就可以保留这部分相关问答，而不必导出全部讨论。

**注意：**筛选后的导出以**完整的一级问答轮次**为单位；不是只保存书签标题，也不是只截取一段被高亮的文字。

## 5. 开启书签筛选后，还能导出完整对话吗？

**可以。**在书签筛选状态下，导出菜单仍提供完整对话与当前筛选范围两种选择：

| 导出选项 | 导出范围 |
| --- | --- |
| HTML · 完整对话 | 全部问答轮次 |
| HTML · 当前书签筛选 | 匹配当前书签或颜色筛选的问答轮次 |
| PDF · 完整对话 | 全部问答轮次 |
| PDF · 当前书签筛选 | 匹配当前书签或颜色筛选的问答轮次 |

因此，**打开筛选不代表完整导出会自动变成筛选导出**。请在菜单中明确选择想要的版本。

HTML/PDF 导出额度与 PRO 权益以当前插件内显示为准。

## 6. 导出后的 HTML 和 PDF，目录上还会显示彩色书签吗？

**会。彩色书签会保留在导出文件的目录信息中，而不只是保留在 ChatGPT 在线侧边栏中。**

### 离线 HTML

离线 HTML 保留一级提问、二级标题形成的目录，以及导出时已有的书签和颜色。打开本地 HTML 文件后，仍可使用目录导航及书签颜色筛选，查看之前标记的重要内容。

HTML 也可保留导出时已有的文字高亮、下划线和备注；但离线 HTML 不能直接作为插件的数据恢复文件。

### PDF

PDF 导出同样保留相关的一级、二级目录结构及书签颜色信息：**PDF 目录页中的彩色书签标记会随文件导出**，PDF 文档大纲也包含对应的颜色数据。不同 PDF 阅读器对文档大纲颜色的实际显示可能不同。

原有的受支持标注也会纳入 PDF 的导出排版，但 PDF 不是可以回写插件的可编辑标注数据库。

**简单区别：HTML 更适合离线搜索和交互式回顾；PDF 更适合固定版式阅读、分享与打印。**

## 7. 只标记二级标题，筛选导出会包含整条回答吗？

**会包含该二级标题所属的完整一级问答轮次。**

例如，某条回答依次包括“问题分析 / 方案 A / 方案 B / 最终结论”。你只给“最终结论”添加红色星标。筛选红色时，目录聚焦这一位置；导出 HTML 或 PDF 时，会保留该标题所属的整个问答轮次，让结论不脱离原始问题和其他解释。

因此，**二级书签精确标记重要位置，筛选导出则保留理解内容所需的上下文**。

## 8. 彩色书签和文字高亮有什么区别？

| 功能 | 主要作用 |
| --- | --- |
| 彩色书签、二级星标 | 标记重要问题或章节，并按颜色分类 |
| 顶部书签筛选 | 从长目录中只看需要回顾的部分 |
| 文字高亮、下划线、备注 | 标记并解释回答中的具体内容 |
| HTML/PDF 筛选导出 | 保存符合当前书签条件的完整问答轮次 |

书签颜色和正文高亮颜色是**独立的**。例如一个回答的书签可以是红色，而其中的公式仍使用黄色文字高亮。

## 9. 书签会在重新安装插件后自动恢复吗？

不会仅因为导出过 HTML 或 PDF 就自动恢复到插件。书签、颜色及标注默认存储在浏览器本地；需要防范重装插件、清除数据或换电脑造成的丢失时，可主动开启 Google Drive 自动备份，并在需要时手动恢复。

详细步骤参见 [ChatGPT 书签备份与恢复指南](/Product-Docs/zh/chatgpt-bookmark-backup-restore/)。
