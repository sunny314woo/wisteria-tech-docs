## 7 天试用什么时候开始？

目前，新用户并不是安装后立即开始倒计时。**在 ChatGPT 中首次使用 HTML 导出入口时，才会启动 7 天试用**。试用期间 HTML 导出不限次数。其他支持的平台可使用已经开启的试用权益，但不会单独启动这段试用期。

同一浏览器配置文件只能开始一次试用。试用结束后，你可以选择继续使用 Free 免费版，无需重新安装。

## 试用结束后哪些功能仍然免费？

- **对话目录与导航**：查看两级目录，跳转到需要的提问与回答。
- **阅读与标注**：使用四色高亮、下划线、备注和书签整理重要内容。
- **Markdown / JSON 导出**：继续保存可编辑、可迁移的对话资料。
- **离线 HTML 导出**：每周免费 1 次；保存为可离线阅读、保留目录和标注的知识页。
- **其他当前开放的免费功能**：以插件内实际显示的权益为准；部分搜索能力仍可能处于开放测试阶段。

Outlinesave 支持 ChatGPT、Gemini、Claude 和 DeepSeek；不同平台的界面和可用入口可能略有区别。

## HTML 免费额度什么时候恢复？

免费 HTML 额度在**每周一 00:00 UTC（协调世界时）**重置。免费版每周 1 次，四个支持的平台共用额度；不会因为切换 AI 平台而分别获得一次。成功导出才消耗额度，导出生成或下载失败不会扣除成功导出次数。

如果只是偶尔保存重要对话，每周一次可能已经够用。如果经常备份研究、学习或编程长对话，可以考虑 Pro 的不限次数 HTML 导出。

## 为什么要导出离线 HTML？

Outlinesave 的 HTML 导出不只是复制聊天文字。它可以把长对话保存为便于离线阅读的知识页，并保留目录、标注、书签及相应的查找功能；代码、数学公式和流程图也能在导出的页面中展示。

比如你花了几周时间用 ChatGPT 排查技术问题，可以先高亮关键结论、加上备注，再导出为 HTML，以后无需重新翻找整段在线聊天。

Outlinesave 采用本地优先的方式处理对话内容，不要求创建 Outlinesave 账号；用户主动选择 Google Drive 备份等外部操作时，则会连接相应服务。

## 常见问题

### 试用期结束后，目录和笔记会消失吗？

不会仅因为试用结束就删除目录相关的本地标注数据。重要资料仍建议自行定期备份。

### 免费用户还能导出 Markdown 吗？

可以。Markdown 和 JSON 导出不占用每周 HTML 免费额度。

### 每周免费 HTML 导出可以累计到下周吗？

每周提供一次免费额度，并在周一 UTC 重置；不要将它理解为可以无限累计的导出次数。

### 我需要卸载重装或注册账号吗？

不需要。试用结束后直接继续使用 Free 即可。

### 我什么时候需要升级 Pro？

当你经常需要在一周内导出多个离线 HTML 知识页时，Pro 的不限次数导出更方便。如果主要使用目录、标注和偶尔导出，欢迎继续使用免费版。
